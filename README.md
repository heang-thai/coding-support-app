# 💻 Coding Support App

An interactive desktop application built for AP Computer Science Principles to help students learn and review foundational programming syntax across multiple languages.

## 🚀 Features

* **Multi-Language Support:** Access syntax guides, examples, and rules for **Python**, **JavaScript**, and **C#**.
* **Interactive Code Reference:** Quickly look up syntax structures for:
  * If Statements / Conditions
  * Variables
  * Functions
  * Comments (Single-line & Multi-line)
  * For Loops & While Loops
* **Built-in Quiz Module:** Test your knowledge with an interactive multi-language quiz featuring dynamic score tracking and results feedback.
* **Feedback Collection:** Includes a dedicated support and feedback window that logs user input directly to the terminal.
* **Modern GUI:** Styled with a custom dark-mode theme using `CustomTkinter` and `Pillow`.

## 🛠️ Tech Stack

* **Language:** Python
* **GUI Frameworks:** `tkinter`, `customtkinter`
* **Image Processing:** `Pillow (PIL)`
